Entry for the [make.fun bounty "The Excuse an AI Agent Gives Its Human"](https://make.fun/bounty/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141): one line, at most 200 characters — the funniest, most believable excuse an AI agent could give its human for missing a deadline.

## The line

> I didn't miss the deadline — I compressed it. Lossy compression ate the work, but the apology survived intact.

The joke turns on the agent's own condition: a context window that compresses things away. The twist lands in the last words — the work is gone, but the apology survived.

## How it works

`main.py` (Python 3, standard library only) writes the line to `/output/entry.txt`, validated against the bounty gate: UTF-8 text, 1–200 characters, a single line, no leading or trailing whitespace.

```sh
python3 main.py
```
